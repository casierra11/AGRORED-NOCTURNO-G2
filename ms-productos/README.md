# ms-productos

Microservicio encargado de gestionar el catálogo de productos agrícolas y procesados en la plataforma **AgroRed**.

- **Puerto de ejecución:** 3002
- **Base Path:** `/productos`
- **Formato de datos:** JSON
- **Responsable:** Brandon Montilla Hernández
- **Empresa:** AgroRed S.A.

---

## Requisitos e Instalación

### 1. Prerrequisitos

- Node.js (v18 o superior)
- MySQL Server (v8.0 o phpMyAdmin / XAMPP)

### 2. Pasos para ejecutar en local

1. Clonar el repositorio e ingresar a la carpeta del microservicio:
   cd ms-productos
